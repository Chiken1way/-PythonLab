# Лабораторная работа №7. Функции и автоматические проверки

Вариант 6: `select_numbers` отбирает числа, равные порогу.

## Файлы
- `functions.py` - функции `sum_digits`, `average`, `normalize_text`, `select_numbers`, `is_palindrome`
- `main.py` - ввод данных и вывод результатов
- `test_functions.py` - проверки через `assert`

## Запуск
```
python main.py
python test_functions.py
```

## Пример
Ввод: `-507`, `-5 0 2 5`, `  ПРИВЕТ   Мир `, порог `2`
Вывод: сумма цифр 12, среднее 0.5, текст `привет мир`, результат `[2]`.

## Для защиты
- Возврат (`return`) отдает значение туда, откуда функцию вызвали, и его можно использовать дальше. `print` только показывает текст на экране.
- Параметр - имя в `def`, он получает значение при вызове. Локальная переменная создается внутри функции и снаружи не видна.
- Тест, который ловит ошибку: если в `select_numbers` написать `n >= threshold`, то проверка `[1, 2, 3], 2 == [2]` упадет с `AssertionError`.
