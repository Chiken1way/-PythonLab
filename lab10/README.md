# Лабораторная работа 10. Текстовые файлы и обработка ошибок

**Индивидуальный вариант: 6.**

## Файлы проекта

- `main.py` — основная программа и проверка положительного целого числа.
- `files_lab.py` — чтение матрицы из файла и функция варианта.
- `table.py` — функции из предыдущей лабораторной работы.
- `test_files.py` — проверки чтения файла и вычислений.
- `matrix.txt` — исходная матрица.
- `report.txt` — пример готового отчёта.

## Формат matrix.txt

Первая строка содержит количество строк и столбцов. Следующие строки содержат целые числа.

Пример:

```text
2 3
1 -2 3
4 0 -6
```

## Вариант 6

Функция `selected_sum(matrix)` складывает элементы, модуль которых больше 2. Исходная матрица не изменяется. Если подходящих элементов нет, функция возвращает 0.

Для матрицы из примера подходят числа `3`, `4` и `-6`:

`3 + 4 - 6 = 1`.

## Запуск

В папке проекта выполните:

```text
python main.py
```

Сначала программа попросит положительное целое число. Для проверки ввода можно по очереди ввести `abc`, `0`, `-2`, `3`. Для первых трёх значений программа покажет разные сообщения, а на числе 3 продолжит работу с `matrix.txt`.

После этого программа прочитает матрицу и создаст `report.txt`.

## Запуск проверок

```text
python test_files.py
```

В тестах временные файлы создаются в отдельной папке с помощью `TemporaryDirectory()`.

## Проверка сохранности старого отчёта

Чтение и проверка всей матрицы, а также вычисления выполняются до открытия `report.txt` в режиме записи. Поэтому при пустом, неверно заполненном или отсутствующем `matrix.txt` программа выводит сообщение об ошибке и не перезаписывает старый отчёт.

## Пример report.txt

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 1
```
