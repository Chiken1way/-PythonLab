# Лабораторная работа 9. Вложенные списки и таблицы

**Индивидуальный вариант: 6 — нули заменить единицами.**

## Файлы проекта

- `table.py` — функции для работы с таблицами.
- `main.py` — ввод таблицы и вывод результатов.
- `test_table.py` — проверки функций.

## 1. Суммы строк

Функция `row_sums(matrix)` проходит по каждой строке таблицы. Внутри строки она складывает все числа и добавляет сумму в список.

Если таблица пустая, функция возвращает пустой список.

## 2. Суммы столбцов

Функция `column_sums(matrix)` считает сумму каждого столбца.

Сначала программа узнаёт количество столбцов. Потом с помощью двух циклов `for` проходит по столбцам и строкам и складывает числа.

## 3. Диагональный узор

Функция `diagonal_pattern(size)` создаёт квадратную таблицу.

- Если номер строки равен номеру столбца, записывается `0`.
- Если строка выше диагонали, записывается `1`.
- Если строка ниже диагонали, записывается `2`.

## 4. Индивидуальный вариант 6

По варианту 6 нужно заменить все нули единицами.

Функция `transform(matrix)` создаёт новую таблицу. Если число равно нулю, в новую строку добавляется единица. В остальных случаях добавляется исходное число.

Исходная таблица не изменяется.

Контрольный пример:

```python
[[-2, 0, 3], [4, -5, 6]]
```

Результат:

```python
[[-2, 1, 3], [4, -5, 6]]
```

## Как устроен ввод таблицы

В `main.py` пользователь вводит количество строк и столбцов, а затем числа каждой строки.

Если в строке введено неправильное количество чисел, программа просит ввести её ещё раз.

После ввода программа выводит исходную таблицу, суммы строк и столбцов, диагональный узор и таблицу после преобразования.

## Проверки

В `test_table.py` используются `assert`, как указано в задании. Проверяются суммы строк и столбцов, пустая таблица, узор и индивидуальный вариант 6.

Также проверяется, что после преобразования исходная таблица не меняется.

## Запуск

Запустить программу:

```bash
python main.py
```

Запустить проверки:

```bash
python test_table.py
```

Если проверки прошли успешно, появится сообщение:

```text
Все проверки пройдены!
```
