# Лабораторная работа 8. Словари, множества и кортежи

**Индивидуальный вариант: 6 — рецепты.**

## Файлы проекта

- `collections_lab.py` — основные задания лабораторной.
- `test_collections.py` — примеры проверки функций.
- `variant_6.py` — индивидуальный вариант про рецепты.

## Какие конструкции использованы

Код сделан по примерам из методички. Используются списки, словари, множества, кортежи, функции, циклы `for`, условия `if`, `sorted()`, `set()`, `.get()`, `split()` и `strip()`.

Дополнительные классы и сложные конструкции не используются.

## 1. Частоты слов

Функция `word_counts(text)` переводит текст в нижний регистр, разделяет его на слова и убирает знаки `.,!?;:` по краям каждого слова.

Для подсчёта используется словарь. Слово — это ключ, количество повторений — значение.

Функция `print_word_counts(counts)` выводит слова по алфавиту.

## 2. Учебные интересы

Функция `common_topics(first, second)` находит общие темы двух списков.

Функция `all_topics(first, second)` находит все уникальные темы.

Для этого списки превращаются в множества. Знак `&` находит пересечение, а знак `|` — объединение. Результат сортируется с помощью `sorted()`.

## 3. Словарь и кортеж

В программе создаётся словарь с ключами `title` и `hours`. Значение `hours` изменяется, затем добавляется ключ `completed` со значением `False`.

Из значений `title` и `hours` создаётся кортеж. Потом кортеж распаковывается в две переменные.

Словарь удобен для записи, потому что у каждого значения есть своё имя. Например, название рецепта можно получить по ключу `title`.

## 4. Индивидуальный вариант 6 — рецепты

В файле `variant_6.py` есть шесть рецептов и три категории: супы, завтраки и основные блюда.

Поле `amount` означает количество порций.

Функция `totals_by_category(records)` считает общее количество порций по каждой категории. Для подсчёта используется `.get()`: если категории ещё нет в словаре, берётся ноль.

Функция `titles_in_category(records, category)` возвращает названия рецептов выбранной категории. Если категория неизвестна, возвращается пустой список.

## Почему нужна сортировка

У множества нет гарантированного порядка вывода. Поэтому используется `sorted()`, чтобы темы выводились по алфавиту.
