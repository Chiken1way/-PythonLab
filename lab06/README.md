## Ответы на вопросы для защиты

**Чем `append()` отличается от присваивания по индексу?**
`append()` добавляет новый элемент в конец, и список становится длиннее. `items[i] = value` заменяет уже существующий элемент, длина не меняется. Если индекса нет в списке, будет ошибка `IndexError`.

**Чем `sorted()` отличается от `sort()`?**
`sorted(items)` возвращает новый отсортированный список, а исходный не меняется. `items.sort()` сортирует сам список и возвращает `None`, поэтому писать `x = items.sort()` нельзя.

**Почему `copy = items` не копия?**
Так оба имени указывают на один и тот же список, и изменение через одно имя видно в другом. Настоящую копию делает `items.copy()`.
